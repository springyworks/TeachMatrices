KosmodTS

Write TypeScript in one source file — see it decomposed into structural blocks on a 2D canvas with semantic connectors derived from the AST.

Classes, interfaces, functions, variables — each becomes a draggable Monaco block. Connections show extends, implements, calls, and uses relationships.

Built with maxGraph + Monaco Editor + TypeScript Compiler API. Fully serverless.
